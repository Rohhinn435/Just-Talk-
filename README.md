# Just Talk — Kerala Open World

This folder contains the current game as `index.html` plus a small WebSocket/WebRTC signaling server for live multiplayer chat, player sync, and voice signaling.

## Run locally
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

For friends on the internet, deploy this folder to a Node.js host with HTTPS/WSS support. The public website name/title is **Just Talk**.
